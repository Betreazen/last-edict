## Открыто

- **Земля — по роду террейна** (3 бита клетки, `TerrainKind` 1…6): у двух игроков одной расы она общая — рост от всех клеток рода,
  кристаллы платят обоим, лечение на своей земле. Перевести землю на владельца клетки (вместе с редактором карт без потолка, Э6).
- **Флаги рас событий** — шесть полей оригинала (`ScenarioEventModel`): раса мода и двое одной расы в событиях не различаются.
- Проверки экранов и бенч — на своих данных (Э5, задача 0): ui-render-check 81 шаг на снимках партии стенда (`tools/CheckSaves`) и
  сценариях импорта, бенч сцен `tools/bench/run_all.py` (`docs/perf-log.md`). Графика импорта в корне не лежит — для сцен `D2_ASSETS_DIR`
  (например, `../disciples-godot/assets`); для шагов с русскими строками импорт — с русификацией (`--l10n`).
- Миграция сценариев и сохранений прежних версий знает id оригинала только по таблице `legacy-ids.json` (мод базы); сущности модов
  оригинала вне таблицы переводятся, если их id содержимого — `base:вид/g000…` (так их называет импорт).
