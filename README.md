# Last Edict

**Last Edict** is an unofficial, fan-made game engine and remake project compatible with **Disciples II: Rise of the Elves**
(GOG 3.01), built on **Godot 4.7** with the game rules in **C# / .NET 10**. It starts from a port that reproduces the original's
behaviour (battle formulas, AI decisions, turn order, economy) and evolves it into a modern game: data separate from code,
mod layers, extension points, any aspect ratio, gamepad support, plain image and sound formats ready for high-resolution art.

> **Fan project. No game data included.** This repository contains no files, art, sound, texts or tables of the original game.
> To play you need your own purchased copy of Disciples II (GOG); Last Edict imports the data from it on first start.
> *Disciples* is a trademark of its respective owners. Last Edict is not affiliated with, endorsed or sponsored by them.

## Requirements

- **Disciples II: Rise of the Elves, GOG version 3.01** — your own copy.
- .NET 10 SDK (pinned in `global.json`) and Godot 4.7.2 .NET to build and run from source.
- Optional: [ffmpeg](https://ffmpeg.org) to import the game's videos (without it the game runs without them).

## Building from source

```bash
git clone <this repository> last-edict && cd last-edict
dotnet build LastEdict.sln
dotnet test LastEdict.sln                                   # runs on the bundled content/test-pack; tests that need game data skip
py tools/import_game.py --game "C:/GOG Games/Disciples II"  # import game data into data/ and assets/ (ignored by git)
godot --path godot                                          # play (Godot 4.7.2 .NET)
```

Running the game without importing first opens a window that asks for your Disciples II folder and imports the data into
`user://game`.

## What is tested without the game

- `content/test-pack` — a small original rule set (two races and neutrals, units, buildings, spells, items, AI settings) and two
  maps, released under CC0 and generated by `tools/test_pack.py`. CI builds and tests the engine on it alone.
- `tests/snapshots` — "port vs port" snapshots: AI-only games with a fixed seed play N days and battles; the state hash after every
  command is compared with the stored file. A rule change shows up as a diff and is accepted on purpose with
  `D2_SNAPSHOTS_ACCEPT=1`. Snapshots of imported scenarios run when game data has been imported.
