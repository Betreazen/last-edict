## Открыто

- **Земля — по роду террейна** (3 бита клетки, `TerrainKind` 1…6): у двух игроков одной расы она общая — рост от всех клеток рода,
  кристаллы платят обоим, лечение на своей земле. Перевести землю на владельца клетки (вместе с редактором карт без потолка, Э6).
- **«Горячий стул» вырезать** (Р33, Э5): лобби, пункт меню, передача хода между людьми за одним ПК, курьер, автобой двух людей в бою.
  Люди одной партии — только по сети (Э7); модель `GameInfo.Humans`/`ActiveHuman` оставить для сети.
- **Выбор расы и расы модов** (Э5): кольцо пяти рас по роду (`ChooseRaceLogic`); каталог рас меню (`data/game/races.json`) — данные
  импорта, а не содержимое; лица лордов, значки мини-карты — по роду.
- **Флаги рас событий** — шесть полей оригинала (`ScenarioEventModel`): раса мода и двое одной расы в событиях не различаются.
- ui-render-check почти целиком на корпусе (шаги боя и полосы — на `corpus/sample`): свой набор шагов на test-pack и импорте (Э5); бенч —
  тоже. Графика импорта в корне не лежит — для сцен `D2_ASSETS_DIR` (например, `../disciples-godot/assets`).
- Миграция сценариев и сохранений прежних версий знает id оригинала только по таблице `legacy-ids.json` (мод базы); сущности модов
  оригинала вне таблицы переводятся, если их id содержимого — `base:вид/g000…` (так их называет импорт).
