**Жёсткие рамки этапа**
- Каждая правка правил — осознанный diff снимков: `D2_SNAPSHOTS_ACCEPT=1 dotnet test --filter Category=Snapshot`, затем `git diff
  tests/snapshots`; в коммите — что изменилось и почему. Правка без правил (рефакторинг) снимков не меняет.
- Ни байта данных оригинала в репозитории и истории (Р3): новые тестовые данные — в `content/test-pack` через генератор.
- Порог полного прогона тестов ≤ 60 с (Р8, Р27) — держать с каждой правкой.
- Публикация (пуш в публичный репозиторий, релизы) — только с подтверждения пользователя.
- Ветки → слияние в `main` (`--no-ff`); ревью подагентом и документы — раз на 3–4 правки, замер — на каждую. Пользователю — по-русски,
  коротко.

**Задачи по порядку (roadmap §4, Э4)**
1. **Ключ правил без формата движка.** Сейчас ключ — id из 10 символов (`UnitGenerator.TypeIndex` кодирует уровни юнитов в id), сущность
   мода без `legacyId` правила не грузят (у test-pack — свои `t000xxA001+`). Ключ — id содержимого (`mod:kind/name`), уровни порождённых
   юнитов — отдельным полем; сохранения — с переносом между версиями (Р18). Снимки не меняются.
2. **Раздельные генераторы** (бой, ИИ, добыча, карта) от зерна партии — A/B баланса на одинаковых бросках. Снимки меняются — принять.
3. **Инициатива на раунд вперёд** (Р4, Р17): случайная часть раунда N+1 — в начале раунда N, эффекты применяются вживую, полоса очереди
   точная на два раунда (`TurnOrder.Build`, `BattleSim.BeginRound`, `RequeueWaiter`, `InsertExtraTurns`, `BattleSession.Upcoming`).
4. **5 рас и больше игроков** (Р6, Р15): одинаковые расы, команды с общей победой, больше 5 игроков, новые расы модами; экраны новой игры
   и дипломатии под N участников. В test-pack — третья раса и карта на 4+ игроков.
5. **Стенд симуляции баланса** (§3.2): headless «N партий × зерно» → JSONL → метрики по расам (доли побед, первый ход, снежный ком);
   параллельно по зёрнам.
6. Перевести на `content/test-pack` и импорт тесты окон, ИИ и карты, которые в эталоне шли на сохранениях корпуса (их список —
   `tools/publish/last-edict.json` эталона, `tests_exclude`).
