`docs/own-version-roadmap.md`, решения Р1–Р34, этапы Э1–Э7). Эталон порта `../disciples-godot` (тег `vanilla-reference`) — только для сверок
с оригиналом. Э1–Э7 сделаны (§4 roadmap, «Э7 — ход»). Ты — **этап Э8 «Доделать сеть»**: то, без чего игра с друзьями по сети неудобна
в настоящих вечерах, — возвращение посреди боя, продолжение партии на другой день, чат, имена и места, и правки по игре пользователя.

**Прочитай по порядку:** `CLAUDE.md` → `docs/HANDOFF.md` (первая строка) → `docs/own-version-roadmap.md` (§1 Р5, Р22, Р23, Р33; §3.5; §4

команду на ПК, ~300 мс через tvd, ~40 КиБ за день. Проверки: тесты 763 + 728 (~20 с), ui-render-check 84 шага, бенч — все «same».

**Жёсткие рамки этапа**
- Правила не меняются: снимки (`tests/snapshots`) — те же строки; сетевая партия — тот же хеш, что повтор журнала хоста.
- Ни байта данных оригинала в репозитории и истории (Р3); снимки экрана — только файлами выпуска `media` (`docs/media.md`), выкладывать
  — с подтверждения пользователя. На снимках лобби — ни настоящего адреса посредника, ни логина (порядок — `docs/media.md`).
- **Секретов и адресов в репозитории нет** — ни в коде, ни в документах, ни в сообщениях коммитов (25.10 адрес уже утекал, историю
  переписывали). Перед каждым коммитом — `git diff --cached | grep -E "[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+"` (кроме 127.0.0.1); вывод драйвера —
  через `sed 's#ws://[^ ]*#ws://<сервер>/ws#'`.
- **tvd:** свой контейнер `le-relay` обновлять можно (исходники — `~/le-relay/src`, `docker build`, тот же `docker run` с
  `-p 8790:8790 -v le-relay-data:/data --memory 256m --cpus 0.5`); чужой прод (`prod-*`, `tvd-*`) не трогать и не перезапускать; новые
  порты и nginx — только с подтверждения пользователя.
- Порог полного прогона тестов ≤ 60 с (Р8, Р27). Публикация (пуш, релизы) — только с подтверждения пользователя.
- Графика — `D2_ASSETS_DIR=../disciples-godot/assets`; `D2_DATA_DIR` не ставить; рабочие копии сносить только `python tools/wt_remove.py`.
- Ветки `e8-<тема>` → слияние в `main` через `../le-wt-main` (`--no-ff`), соседям — сообщение до бенча и слияния; ревью подагентом раз на
  3–4 правки, замер на каждую (`ab.py` против `../le-wt-main`, `perf-log.md`). Окно — `--position 3900,541`. Пользователю — по-русски,
  коротко; маршруты по интерфейсу — спрашивать у него.

**Задачи по порядку**
0. **Перед началом:** ветка `e8-*`, `git -C ../le-wt-main log -1`, `ListAgents` и сообщение соседям; тесты, CI-сборка и
   `py tools/net-duo.py --case duel --days 2` зелёные.
1. **Игра пользователя.** Попросить пользователя сыграть с другом (или на ПК + EliteBook руками) через лобби: создать комнату, войти по
   коду, пару дней с боем, обрыв, асинхронный ход. Его замечания — первыми правками этапа.
2. **Возвращение посреди боя людей.** Сейчас сторона, которой не было на связи в миг начала боя, экрана не получает, а потерянный шаг
   не досылается (номер шага `BattleStep.Index` не проверяется). Хост держит идущий бой людей (запрос и шаги по порядку): вернувшийся —
   получает запрос и все шаги, экран догоняет показ; номер шага — подтверждение и досылка пропущенных; дубли — мимо. Драйвер: `duel`
   с обрывом посреди боя.
3. **Сетевую партию — продолжить в другой день.** Хост записывает сетевую партию (своё сохранение с комнатой и местами), позже
   открывает её из «Моих комнат» — друзья возвращаются по своим ключам, партия идёт дальше с тем же хешем. Хост пропал посреди партии —
   клиенты видят «хост не на связи», не виснут.
4. **Места и имена.** Хост садит клиентов по порядку приветствий, а имена лордов берутся по порядку входа в лобби — может не совпасть.
   Место друга — то, что выбрал хост в лобби (по соединению у посредника); имя лорда — его ник. Посредник сверяет имя места с людьми
   партии (асинхронная комната: список людей приходит с первой записью).
5. **Чат в игре.** Строка ввода на карте (клавиша и геймпад — по `data/ui/input.json`), сообщение `chat` уже есть в протоколе; показ —
   строками чата карты с ником; в асинхронной партии — по желанию пользователя.
6. **Мелочи Э7:** имена сценариев в лобби с кавычками из имени файла (`'Orc Champions'`); у второго экрана боя людей итог без опыта
   («опыт=-»); ник и код комнаты — подсказки в полях.

**Готово, когда:** вернувшийся посреди боя людей видит тот же бой и доигрывает его, хеш = повтор журнала; сетевая партия продолжается
после закрытия игры хостом; имена и места совпадают с выбранными в лобби; чат работает на двух машинах; замечания пользователя по игре —
исправлены; снимки правил — те же; roadmap §4 «Э8 — ход» с числами; строка в начале `docs/HANDOFF.md`; README — строка «Progress» (снимки
— с подтверждения пользователя); следующая сессия — `docs/session-e9-prompt.md` (план — с пользователем).
